# TARMAC — The Art of Motion

Sitio web de fotografía y video de motorsport: enduro, drift, rally, pista y coches de lujo.

- `index.html` — sitio completo autocontenido (imágenes, estilos y scripts integrados)
- `vercel.json` — configuración de despliegue estático en Vercel
